# Stage 10 — isolated final frontend preview

To jest wyłącznie podgląd docelowego frontendu MOL App V2.

- dane są demonstracyjne,
- finalny frontend nie wykonuje jeszcze realnych zapisów do backendu,
- `/v2/` pozostaje testowym frontendem backendu,
- V1 pozostaje nietknięta,
- brak nowych zapisów Moniti,
- automatyczne alerty OFF/HOLD.

Po audycie kompletności 2026-09-07 preview zawiera m.in. natychmiastową aktywację procesu MAGAZYN, opcjonalne narzędzia magazynowe, pełne stany dnia, ważone raportowanie wydajności, oddzielny raport czasu pracy i komunikację lidera.
